# Plan: Luxury Shoe Store Landing Page

Build a sophisticated, high-conversion landing page for a luxury shoe brand based on the provided requirements.

## Proposed Changes

### 1. Structure and Content
*   **Hero Section**: High-impact headline "Onde a Arte do Calçado Encontra a Sua Distinção", elegant subheadline, and primary CTA "Explore a Coleção Exclusiva".
*   **Essência da Nossa Arte**: Narrative about craftsmanship and materials (About section).
*   **Collection Highlights**: Featured categories for Women, Men, and Limited Editions.
*   **Diferenciais**: Key value propositions (Noble materials, manual craftsmanship, ergonomic comfort, exclusive design).
*   **Testimonials**: Social proof with refined cards.
*   **Final CTA**: Encouragement to view all collections or book a private experience.
*   **Footer**: Contact info, social links, and legal links.

### 2. Design and UX
*   **Typography**: Serif for headings (e.g., Playfair Display or similar) and Sans-serif for body (e.g., Inter/Jakarta).
*   **Color Palette**: Neutral luxury (Black, White, Charcoal, Ivory, Deep Brown) with gold accents.
*   **Responsiveness**: Fully optimized for mobile, tablet, and desktop.
*   **Components**: Use shadcn/ui for modern, accessible components (Buttons, Cards, Carousels).

## Technical Details

*   **File Modifications**:
    *   Rewrite `src/routes/index.tsx` to implement the landing page structure.
    *   Use `@tanstack/react-router` for routing and `head()` for SEO.
    *   Implement Tailwind CSS for styling.
    *   Add relevant icons from `lucide-react`.
